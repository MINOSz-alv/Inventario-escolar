# Proyecto: Inventario escolar - Cecytem Plantel Tecámac

Estructura inicial con backend en Django + DRF y frontend básico en Expo (React Native).

Pasos rápidos:

- Backend: ver [backend/README.md](backend/README.md)
- Frontend:

```bash
cd frontend
npm install
npm start
```

- App de escritorio local:

```bash
cd desktop
npm install
npm start
```

Nota: La app de escritorio usa el backend local en `http://127.0.0.1:8000/api`.
