# Proyecto: Inventario escolar - Cecytem Plantel Tecámac

Estructura inicial con backend en Django + DRF y frontend básico en Expo (React Native).

Pasos rápidos:

- Backend: ver [backend/README.md](backend/README.md)
- Frontend:

```bash
cd frontend
npm install
npm start
```

Nota: Ajusta `API_BASE` en `frontend/App.js` según tu emulador o dispositivo.
